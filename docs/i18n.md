# Translate the Perkify interface

Write new interface copy in English. Use `<Translate text={"Your message"} />` for displayed text or `t("Your message")` from `useLanguage()` for string props. Use double quotes so the translation script can find new messages.

Use named placeholders for values that change. For example, use `t("Page {page} of {pages}", { page, pages })`. Keep a sentence together so translators can change its word order.

Run `pnpm translations:check` to find missing translations. To generate them, set `GOOGLE_TRANSLATE_API_KEY` in your shell and run `pnpm translations:sync`. Review the changes to [messages.json](../apps/web/lib/i18n/messages.json) before committing. The script sends interface strings to Cloud Translation during development. [Cloud Translation REST reference](https://cloud.google.com/translate/docs/reference/rest/v2/translate)

To add a language, register its locale, native label, and translation target in [locales.json](../apps/web/lib/i18n/locales.json), then run the sync. The language appears in the selector. A missing translation displays the English source.

## Translate published quests

Set `GOOGLE_TRANSLATE_API_KEY` in the API server environment or root `.env.local` and restart the API. The quest detail sends the title, description, criteria, checklist, and milestones to Cloud Translation when a signed-in reader selects **Translate quest**. The translation is displayed alongside a way to return to the original. Drafts and archived quests cannot be translated.
